# Support

## How to file issues and get help

This project uses [GitHub Issues](https://github.com/microsoft/security-devops-common/issues) to track bugs and feature requests. Please search existing issues before filing new ones to avoid duplicates.

When filing an issue, please include:

- The plugin name and version (from `plugin.json` or `marketplace.json`)
- Steps to reproduce the problem
- Expected vs. actual behavior
- Your OS and Copilot CLI version (`copilot --version`)

## Microsoft Support Policy

Support for this project is limited to GitHub Issues. Response times are best-effort and not guaranteed.
